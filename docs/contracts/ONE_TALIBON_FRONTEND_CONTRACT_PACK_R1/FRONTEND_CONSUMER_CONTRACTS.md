# Frontend consumer contracts — practical source-backed draft
**Producer baseline:** [canonical source](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/routes/web.php) `7b4ebb838982f6262b9fef65d18ba57488ebf941`; no contract acceptance inferred by publishing this file.

## Transport baseline for AJ and Jhayr
1. Laravel + Inertia pages: `GET` page routes produce Inertia component names and props; ordinary forms mutate via Laravel session-authenticated web routes and usually redirect with flash. `GET /login` and `POST /login`: `email` (required email), `password` (required string), optional `remember` boolean; sessions are regenerated on login and invalidated on logout ([controller](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/Auth/AuthenticatedSessionController.php)).
2. Web access gate: grouped `auth`, `active`, `mfa.assured` except designated login, MFA challenge/enrollment and logout paths. Protected pages may redirect to login or MFA. Never infer permissions from a visible sidebar tab alone.
3. Shared props on **non-public, non-JSON Inertia requests ONLY**: `appName: string`, `workspaceExperience: 'employee'|'department_head'|'executive_oversight'|'system_administration'|null`; `auth.user: {id,name,email,role,employee}|null`; nested `employee: {employee_number, position, department}|null`; `permissions: {reports, navigation}`; `flash: {success?,error?}`. `department` fields: `id,code,name,short_name,branch?,office_type?,is_routable?`. Source: [HandleInertiaRequests](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Middleware/HandleInertiaRequests.php) + [types.ts](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/resources/js/types.ts). Do not assume the whole object is shared on public pages or JSON endpoints: public named routes share only `appName`, `authenticated` plus parent props; `expectsJson()` returns parent props only. `auth.user.employee` can be null until assurance. Source does not project department `is_active` in these shared props; client types must not invent it.
4. CSRF: same-origin Laravel web POST/DELETE must carry token/cookie; handle expired session (419) via retry/relogin, not silent success. [ApplicationErrorResponse](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Services/ApplicationErrorResponse.php) returns a flash redirect on 419 where applicable; JSON-accepting requests stay native. HTTP errors must retain proper status.
5. Task JSON is an exception to Inertia forms, **not** a bearer-token API; [EnsureTaskJsonAccept](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Middleware/EnsureTaskJsonAccept.php) forces `Accept: application/json` on `/tasks*`.

## Confirmed request fields
- Work Request create: `transaction_type` enum `internal_request|project_endorsement|document_review|funding_request|other`; optional `request_category`, `request_type`, `action_required`; `title` required max 255; `description` max 5000 nullable; `priority` normal/high/urgent; `target_department_id` required active/routable; `assigned_employee_id` nullable active in target department; `due_at` >= today nullable; `remarks` max 2000; plus `CoreEvidenceRules` ([StoreWorkRequestRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/StoreWorkRequestRequest.php)).
- Work Request list filter `view` one of `overview,all,needs_my_action,assigned_to_me,my_requests,office_queue,unassigned,overdue,due_soon,recently_updated,waiting_on_others,recently_completed,staff_workload,escalations`; optional `search` max 120, status max 40, priority enum, office_id, page >=1 ([TransactionIndexRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/TransactionIndexRequest.php)). Transition `action` must come from server-resolved workflow definition, plus optional target office, assignee, remarks and evidence.
- Correspondence classify: enum `CorrespondenceClassification`, optional remarks max 2000; route: required active/routable `target_department_id`, priority enum, optional future/today `due_at`, remarks max 2000; register/act use evidence/remarks as declared by their FormRequests. Distinguish `/workspace/*` Inertia redirect outcomes from direct JSON lifecycle endpoints.
- Record search: `mode=files|records`, `view=overview|register`, archive scope `all|my_sent|my_received|my_uploads`, record_type `all|correspondence|transaction|travel_order`, optional filters and page >=1 ([RecordsIndexRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/RecordsIndexRequest.php)).
- Memorandum issue: `memo_number` required unique max 80, `title` max 255, `body` max 20000, `audience_type` `all|departments|employees`, `audience_ids` array, `requires_acknowledgement` boolean, `classification` `internal|public|confidential`, `expires_at` nullable future; `canPublish` server authorization ([MemorandumController](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/MemorandumController.php)).
- Messaging: `GET /messages/feed?channel=<MessagingChannels>&after=<integer>=0`; first page last 50 chronological, cursor fetch max 100 ascending. `POST /messages/feed` requires `channel` in enum and `body` trimmed, max 2000; `MessageResource` has `publicId,cursor,channel,body,createdAt,sender:{name,office},isMine` ([resource](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Resources/Messaging/MessageResource.php)).
- Calendar response `events[]` with `id,event_key,event_type,title,description,priority,starts_at,ends_at,all_day,start_date,end_date,start_time,end_time,location,action_url,status,department,calendar_bucket`; `calendar:{view,anchor_date,today,range_start,range_end,timezone}`. Fields such as ends_at, location and department may be null; an invalid `view` falls back to `month`, an invalid `date` to today (not a 422); events have a bounded date range but no record-count cap. ([query service](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Services/CalendarWorkspaceQueryService.php)).
- A01-C1 exact fields, enums, errors, statuses in [module spec](MODULE_A01_C1_TASK.md); no universal client-provided `state`, `actor_id`, source links, or office routing.

## Explicit schema gaps before acceptance
The exact *entire* nested Inertia projections of dashboard, work queue, correspondence, archive, admin, reports and executive surfaces require typed schema extraction and a backend/frontend contract test tied to **the actual importer SHA**. This draft intentionally does not fabricate fields beyond source-checked controls above. Role/office configurations remain subject to LGU validation. See [holds](AUTHORITY_AND_INTEGRATION_HOLDS.md).
