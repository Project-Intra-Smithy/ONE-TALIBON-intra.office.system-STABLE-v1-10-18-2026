# Work Requests + Correspondence — source-observed adapter notes
**Pin:** backend `7b4ebb838982f6262b9fef65d18ba57488ebf941`. Neither family is declared 'newly released' by this document.

## Work Requests are NOT Task C1
- `GET /transactions` returns Inertia `Transactions/Index` from [TransactionController::index](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/TransactionController.php), [WorkQueueQuery](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Services/WorkQueueQuery.php) and validated [TransactionIndexRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/TransactionIndexRequest.php). Filtering `view` enum, `search`, `status`, `priority`, `office_id`, `page`. No guessed shared `GET /my-work` endpoint.
- `GET /transactions/create` returns `Transactions/Create` with `departments`, `assignableEmployees`, `requestCategories`, `actionOptions`; `POST /transactions` validates [StoreWorkRequestRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/StoreWorkRequestRequest.php) and redirects to new show with flash. Required title (max 255), priority, active/routable target office; enum transaction type. Optional request category/type/action, description (max 5000), office-scoped assignee, due date >= today, remarks (max 2000), evidence. No `Task` `state` field here.
- `GET /transactions/{id}` authorizes per WorkflowTransaction policy; returns detail `transaction`, `departments`, `assignableEmployees`, `accountability`, `transactionPermissions`, `evidence`, `relatedWork`. `POST /transactions/{id}/transition` validates [TransitionWorkRequestRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/TransitionWorkRequestRequest.php); `action` must be permitted by `WorkflowDefinitionResolver` and per-actor policy. Redirect includes return-navigation state; do not client-create states.
- `GET /transactions/{id}/live?after_event_id=...` is a same-origin JSON event delta with authorization. Existing [Show](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/resources/js/pages/Transactions/Show.tsx) polls at 4000 ms, ignores invalid/non-200 JSON without visible error. When imported, request separate remediation: stale-state indicator, session handling, resource/identity race test.

## Correspondence has two web-consumer shapes
- Inertia workspace: `GET /correspondence` returns `Correspondence/Index` with `records` paginated, `overview`, `filters`, `filterOptions:{lifecycles,classifications,offices}`, `workspace:{departmentName,departmentCode}`; existing user must have department ([CorrespondenceWorkspaceController](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/CorrespondenceWorkspaceController.php)). `GET /correspondence/{id}/workspace` returns `Correspondence/Show` with workspace presenter payload.
- Inertia writes: `POST /correspondence/{id}/workspace/{register,classify,route,act}` use [WorkspaceActionController](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/CorrespondenceWorkspaceActionController.php), FormRequests incl [RouteRequest](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Requests/CorrespondenceWorkspaceRouteRequest.php); redirect/flash on success. `register` validates evidence; `classify` enum classification, `remarks` nullable <=2000; `route` target active/routable department ID, priority enum normal/high/urgent, nullable due_at >= today and remarks; `act` nullable remarks, evidence.
- Direct lifecycle JSON: `GET /correspondence/{id}`, `POST /correspondence/{id}/{register,classify,route,act}` yield JSON `correspondence` and correlation ID from [CorrespondenceLifecycleController](https://github.com/Project-Intra-Smithy/Talibon-Sales-Prototype/blob/7b4ebb838982f6262b9fef65d18ba57488ebf941/app/Http/Controllers/CorrespondenceLifecycleController.php). E.g., register has `public_id,reference,lifecycle_state,registered_at`; classify adds `classification,classified_at`; route returns `routed_at,workflow_reference`; act returns `action_started_at,workflow_reference,workflow_status`. Null timestamps/references are possible. Do **not** assume the JSON payload is interchangeable with the Inertia presenter.
- No new official correspondence classification values, cross-office rights or LGU approval workflow should be invented; server source policies and pending process authority constrain final front-end actions.

## Shared adapter checks
The client must preserve source `id` vs `public_id`, nullable department, flash success/errors, native 403/404/422, 419 CSRF, exact return context and server pagination. Tests must include out-of-office ID, invalid office/due date, disallowed action, stale event cursor and document evidence. Do not import full backend into the frontend workspace.
